Add tournaments, club battles, lectures and simuls. The recurring Sunday, Tuesday and Thursday nights are built into the site — they are not listed here. Anything you save appears on the site within a minute.

Access

Paste a GitHub token with write access to Ruptzy/kava-club. It is stored only in this browser and never leaves it except to talk to GitHub.

Making a token, once:
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: kava-site · Expiration: whatever you like
  3. Repository access: Only select repositories → Ruptzy/kava-club
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate, copy it, paste it above. Keep it to yourself — anyone with it can change the site.
