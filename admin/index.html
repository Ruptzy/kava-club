Access

Paste a GitHub token with write access to Ruptzy/kava-club, and choose a passphrase. The token is encrypted with that passphrase before it is stored, so it is useless to anyone who opens this page without it.

This device has a locked token saved. Enter the passphrase to use it.

Making a token, once:
  1. Open github.com/settings/personal-access-tokens/new
  2. Token name: kava-site · Expiration: 90 days is sensible
  3. Repository access: Only select repositories → Ruptzy/kava-club
  4. Permissions → Repository permissions → Contents: Read and write
  5. Generate, copy it, paste it above with a passphrase you will remember.

If the token is ever lost or shared, revoke it on that same GitHub page and make a new one — that instantly stops anyone using it.
